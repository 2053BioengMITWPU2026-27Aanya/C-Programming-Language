# C Programming Assignments (3 – 10)

A collection of foundational C programming assignments covering control structures, arrays, strings, functions, recursion, structures, pointers, file handling, and calendar generation.

## Repository Contents

| Assignment | Program / Topic | Key Concepts Covered |
| :--- | :--- | :--- |
| **Assignment 3** | **Menu-Driven Calculator** | `switch-case` statements, arithmetic operators, user input |
| **Assignment 4** | **2D Matrix Addition** | Two-dimensional arrays (`2x3`), nested `for` loops |
| **Assignment 5** | **String Operations Menu** | `<string.h>`, `<ctype.h>`, `strlen()`, `toupper()`, `tolower()`, `while(1)` |
| **Assignment 6** | **Factorial (Iterative & Recursive)** | `for` loops, recursion, base cases, function prototypes |
| **Assignment 7** | **Student Result Management** | `struct`, arrays of structures, percentage & pass/fail logic |
| **Assignment 8** | **Swap Two Numbers** | Pointers, pass-by-reference, memory addresses (`&`, `*`) |
| **Assignment 9** | **File Copy Utility** | File I/O (`fopen`, `fclose`, `fgetc`, `fputc`), `FILE` pointers, `perror` |
| **Assignment 10** | **Calendar Generator** | Date/day calculations, leap year logic, formatted console output |
